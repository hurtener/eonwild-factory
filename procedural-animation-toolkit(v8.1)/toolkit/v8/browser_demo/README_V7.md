# V7 browser validation player

Copy these files beside the generated pack:

```text
index-v7.html
v7-viewer.js
tarbosaurus_procedural_v7_animation_pack.glb
animation-manifest.v7.json
```

Run:

```bash
python3 serve.py
```

The player is dependency-free WebGL2. It supports the complete 75-joint source skin, three JOINTS/WEIGHTS sets, exact authored action handoffs, active control state, timeline scrubbing, root-motion camera follow, and cumulative root displacement for looping locomotion.
