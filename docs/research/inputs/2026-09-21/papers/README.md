# Supplied research papers

These are byte-identical copies of the four PDFs supplied by the user for the
locomotion investigation. Original paths and SHA256 hashes are recorded in
../source-audit.json; committed locations are in ../handoff-source-manifest.json.
They are reference material, not runtime assets or an Eonwild-authored work.
Preserve the authors' attribution and the rights notices inside each paper.
