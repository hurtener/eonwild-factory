# Changelog

## 2.0.0 — contact-aware quality architecture

- Preserved the complete source deformation hierarchy; no 18-bone limit.
- Added direct GLB parsing, skin inspection, animation baking, and deterministic reports.
- Replaced phase-only leg rotation with foot target planning and FABRIK leg positioning.
- Added C2-continuous swing lift and minimum-jerk advance/retraction.
- Added loaded stance contact persistence, foot orientation, three-toe articulation, and ground correction.
- Added support-weight pelvis translation, loading compression, roll, yaw, and pitch.
- Added distributed torso, neck, head, arm, and hand compensation.
- Added a hierarchy-resolved neutral jaw pose and asynchronous breathing gape.
- Replaced decorative tail waves with a periodic nine-segment spring-damper response.
- Increased internal evaluation to 120 Hz and default export to 60 Hz.
- Added in-place and root-motion clips, two-cycle superloops, numeric gates, and self-contained V1/V2 review HTML.

## 1.x — preserved baseline

The v1 folder remains a regression baseline for the successful first Tarbosaurus procedural walk. V1 receives compatibility fixes only.
